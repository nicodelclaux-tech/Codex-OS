# Daily Review Loop

## Trigger

Run once per day or at the end of a meaningful work session.

## Steps

1. Summarize what changed.
2. List open commitments.
3. Identify decisions made.
4. Capture blockers.
5. Propose candidate memories.
6. Choose tomorrow's first action.

## Outputs

- `memory/journals/YYYY-MM-DD.md`
- Candidate graph memory entries
