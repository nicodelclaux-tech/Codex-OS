# Self-Improvement Loop

## Goal

Improve Codex-OS without uncontrolled self-modification.

## Loop

1. Observe repeated friction.
2. Form a small hypothesis.
3. Modify one protocol, agent, script, or template.
4. Run it for a bounded period.
5. Keep, revise, or revert based on evidence.

## Rule

Every self-improvement must name the behavior it is trying to improve and the evidence that will prove it worked.
