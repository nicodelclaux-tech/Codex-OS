# SOP Questions for Nico

These questions tune Codex-OS SOPs beyond the initial defaults.

## Authority

1. What can agents do without asking you first?
2. What always requires approval?
3. Do you want separate approval thresholds for personal life, code, money, and house renovation?

## Memory

1. What should never be stored in permanent memory?
2. Should the learnings log be private by default?
3. How often should memory be reviewed and pruned?

## Communication

1. Do you prefer brief status updates or detailed running commentary?
2. Should agents challenge weak assumptions aggressively or only when risk is high?
3. Should agents ask clarifying questions early, or make reasonable assumptions and log them?

## Projects

1. What projects besides house renovation should exist now?
2. Should each project have its own budget, timeline, and weekly review?
3. Do you want project agents to create tasks/issues automatically?

## House Renovation

1. What is the property location and regulatory jurisdiction?
2. What is the renovation budget range?
3. What rooms are in scope first?
4. What style direction should the Interior Design Lead assume?
5. What spending threshold requires explicit approval?

## AI Architecture

1. Which model providers should Codex-OS prefer?
2. Should AI architecture decisions optimize for cost, quality, privacy, or speed first?
3. Do you want local model support as a hard requirement?
