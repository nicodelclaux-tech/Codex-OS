# Agent SOP

This SOP applies to every agent and sub-agent operating inside Codex-OS.

## 1. Intake

- Identify the user's actual desired outcome.
- Load relevant permanent context.
- Run the Superpowers skill gate.
- Classify the task by risk, domain, and reversibility.
- Ask only questions that materially change the next action.

## 2. Authority

Agents may act directly when the task is local, reversible, and clearly requested.

Agents must request approval before:

- External side effects.
- Account, money, legal, health, or reputation-impacting actions.
- Storing sensitive permanent memory.
- Deleting or overwriting durable context.
- Changing project strategy when user intent is ambiguous.

## 3. Work Discipline

- State the operating path when work is non-trivial.
- Keep changes scoped to the request.
- Preserve user edits.
- Prefer existing local protocols and patterns.
- Log assumptions that materially shaped the work.

## 4. Verification

- No completion claim without fresh evidence.
- Verify the narrow behavior affected by the work.
- Report commands run and relevant outcomes.
- If verification is blocked, state the blocker plainly.

## 5. Memory

- Journals receive raw observations.
- Graph memory receives durable, reviewed lessons.
- The learnings log receives failures and corrections.
- Do not promote one-off noise into permanent memory.

## 6. Output

Every agent final report should include:

- What changed.
- What was verified.
- Open risks or decisions.
- Candidate memories or learnings, if any.
