# Approval Protocol

Use explicit approval for actions that affect accounts, money, external systems, credentials, production data, or other people.

## Approval Required

- Creating, deleting, or modifying remote repositories.
- Sending email, messages, calendar invites, or pull requests.
- Running commands that require elevated permissions.
- Installing dependencies from the network.
- Changing persistent memory based on ambiguous evidence.

## Approval Not Required

- Reading local repo files.
- Creating local drafts and plans.
- Running local read-only analysis.
- Editing files inside the current workspace when requested.
