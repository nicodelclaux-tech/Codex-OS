# Principles

## System Principles

- Local-first is the default.
- Memory is earned through evidence.
- Agents operate with scoped authority.
- External actions require explicit approval.
- Every loop must leave an audit trail.
- The OS should reduce context rebuilding, not create busywork.

## Engineering Principles

- Prefer boring storage formats: Markdown, JSON, JSONL, SQLite.
- Keep protocols readable by humans and agents.
- Version important context changes.
- Automate repetitive review, not judgment.
