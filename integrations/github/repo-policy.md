# GitHub Repo Policy

## Branches

- `main`: stable operating system context.
- `experiment/*`: protocol or agent experiments.
- `automation/*`: generated workflow changes.

## Commit Rules

- Commit protocol changes separately from memory changes.
- Do not commit secrets.
- Include why a durable context change was made.

## Issues

Use issues for:

- Automation backlog
- Protocol bugs
- Missing integrations
- Recurring friction
