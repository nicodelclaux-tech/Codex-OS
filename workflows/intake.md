# Intake Workflow

Use this when a new idea, project, commitment, or integration enters Codex-OS.

## Intake Fields

- What is being requested?
- Why does it matter?
- What system does it touch?
- Is approval needed?
- Is this a one-off task or durable context?
- What is the next physical action?

## Routing

- One-off task: execute or schedule.
- Durable preference: journal first, promote later.
- Project: create project context.
- Integration: add adapter spec under `integrations/`.
- Automation: add to automation backlog.
