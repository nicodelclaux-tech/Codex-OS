# Chief of Staff Memory Retrieval Workflow

Use before routing strategic, project, memory, or high-context requests.

## Retrieval Order

1. Permanent context.
2. Graphify public memory.
3. Relevant project memory.
4. Learnings log.
5. Private memory, only when available and approved for the task.
6. Recent corrections.

## Routing Impact

- Preferences affect communication and decision style.
- Commitments affect scheduling and follow-up.
- Learnings affect prevention rules.
- Project facts affect specialist routing.
- Corrections override older memories.

## Output

When memory meaningfully affects a response, state the memory used in plain language unless privacy or brevity argues against it.
