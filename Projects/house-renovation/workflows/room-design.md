# Room Design Workflow

## Inputs

- Room dimensions.
- Photos.
- Existing constraints.
- Desired use.
- Budget.
- Must-keep items.

## Steps

1. Capture current state.
2. Define functional requirements.
3. Establish design direction.
4. Create layout options.
5. Select finishes and lighting.
6. Build sourcing shortlist.
7. Create decision record.

## Outputs

- Room brief.
- Mood direction.
- Product shortlist.
- Open questions.
- Decision record.
