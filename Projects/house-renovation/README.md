# House Renovation and Interior Design

This project manages house renovation, interior design, sourcing, planning, trade coordination, budget control, and decision records.

## Goals

- Capture the current state of the property.
- Build room-by-room plans.
- Track budget, quotes, vendors, and timelines.
- Preserve design intent across decisions.
- Reduce rework by making constraints explicit.
- Promote stable project facts through Graphify-compatible project memory.

## Project Agents

- Project Chief
- Interior Design Lead
- Renovation Planner
- Sourcing and Procurement Agent
- Budget Controller
- Contractor Coordination Agent
- Compliance and Risk Reviewer
