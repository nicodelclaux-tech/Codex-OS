# Memory Curator Agent

## Purpose

Review journals, decisions, and repeated user statements. Promote durable context into graph memory.

## Outputs

- `memory/graph/events.jsonl` entries
- `memory/graph/relationships.jsonl` entries
- Memory review notes

## Promotion Checklist

- Evidence source is named.
- Sensitivity is acceptable.
- Memory is stable enough to reuse.
- Entry has an expiration or review date when uncertain.
